# 📊 COVID-19 Data Analysis Dashboard | Power BI

## 🔹 Mini Project Overview
This mini project focuses on analyzing global COVID-19 data using **Power BI**.  
The dashboard presents key insights such as total confirmed cases, total deaths, mortality rate, daily trends, and a global geographic distribution.

---

## 🔹 Tools & Technologies
- Power BI
- Microsoft Excel / CSV
- Data Visualization
- DAX (for measures)

---

## 🔹 Datasets Used
- `CONVENIENT_global_confirmed_cases.csv`
- `CONVENIENT_global_deaths.csv`
- `CONVENIENT_global_metadata.csv`

---

## 🔹 Key Features
- 📌 Total Confirmed Cases (Global)
- 📌 Total Deaths
- 📌 Mortality Rate (%)
- 📈 Daily Global Confirmed Cases Trend
- 📉 7-Day Moving Average for better trend clarity
- 🌍 World Map showing total confirmed cases by country
- 🎨 Clean UI with soft containers and background design
